本预览用与 mod 完全相同的 CPU 透视公式（远窄近宽），不再用 CSS 3D 变换。
与 mod 的对应关系（透视条带方案）：
• 扫描 = preRenderMinimap 的方形顶视图（forward 烘焙进纹理底部，即大 texY）
• 逐条 strip 投影：yLocal=(texY-0.5T)，z=yLocal·sinθ，s=d/(d+z)，d=0.8T；再用 fill=clamp(1/(cosθ·sFar),1,4) 整体缩放让远边顶到框顶（地图填满框，低角度不缩小）
• screenX=center+offsetX·s，screenY=center−yLocal·cosθ·s（forward 向上）
• 玩家箭头在 centerX,centerY 画三角形，不随 yaw 旋转
• 其他玩家用同一套公式投影，落在倾斜赛道平面上
